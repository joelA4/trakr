## 📌 Proyecto: **Trakr** – App de finanzas personales (Vue 3)

### 🧠 Objetivo general

Aplicación web para **gestionar carteras (wallets), transacciones, presupuestos y reportes**, construida con **Vue 3 + Composition API + Pinia**, siguiendo una arquitectura escalable y modular.

---

## 🏗️ Arquitectura y estructura

* Proyecto organizado por **responsabilidad**, no por tamaño.
* Separación clara entre:

  * **Views** (pantallas principales)
  * **Components** (reutilizables y específicos)
  * **Stores (Pinia)** para el estado global
* Uso de **layout principal** con navegación persistente.

📁 Ejemplo:

```
views/
components/
  ├── layout
  ├── ui
  ├── forms
  ├── dashboard
stores/
router/
```
